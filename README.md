# java-calculator-precourse


## 기능 구현 목록
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.


### 입출력기
- [x] 유저의 입력을 전달한다.
- [x] 결과값을 출력한다.

### 전처리기
- 공통
    - [ ] 유저의 입력을 바탕으로 숫자와 연산자를 분리한다.
    - [ ] 마지막 문자가 연산자로 끝나면 예외처리한다.
    - [ ] 연산자 이외의 다른 문자가 들어왔으면 예외처리한다.
    - [ ] 음수가 들어온다면 예외처리한다.
    - [ ] 입력값이 범위를 벗어난다면 예외처리한다.(Long)
    - [ ] 입력값이 실수라면 예외처리한다.
    - [ ] 입력값이 공스트링이면 예외처리한다.
    - [ ] 입력값 사이에 공백이 있으면 무시한다.


- 커스텀 구분자가 없을때
    - [ ] 첫 문자가 숫자가 아닌 문자로 시작하면 예외처리한다.


### 커스텀연산자관리기
- [x] 커스텀 구분자의 시작문자와 끝문자를 체크한다.
- [x] 커스텀 구분자가 길이가 1인 문자(char)인지 체크한다.
- [x] 커스텀 연산자가 있는지의 여부와 그 커스텀 연산자를 저장한다.
- [x] 커스텀 구분자가 기본 구분자면 예외처리한다.
- [x] 커스텀 구분자가 숫자면 예외처리한다.


### 덧셈기
- [x] 숫자들을 더하고 결과를 반환한다.
- [x] 숫자들의 결과값이 범위를 넘는다면 예외처리한다. (Long)


## 제약사항
- 커스텀 구분자에 숫자와 공백은 들어오지 않는다고 가정한다.
- 숫자는 정수 양수에 한정한다. (.이 커스텀 구분자로 들어오면 혼동이 생기기에.)
